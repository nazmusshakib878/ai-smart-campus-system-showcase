# AI Smart Campus System

A modern university management platform designed to simplify academic operations and support students, faculty, and administrators.

## Live demo

[Open the live application](https://ai-smart-campus-system-ce9i.onrender.com)

## Highlights

- Role-based portals for Administrator, Faculty, and Student
- Student monitoring, courses, attendance, notices, and campus services
- Academic data and campus management tools
- AI assistant experience for campus-related questions
- Responsive, professional interface

## Technology

Laravel • Vue • MySQL • REST API

## Project note

This is a public project showcase. The production source repository is private to protect the project code and deployment configuration.
